# Implementacja kolejki oraz stosu. 

Obie klasy muszą dziedziczyć od klasy abstrakcyjnej (ex. AbstractDataStruct), zawierającej wspólne pola i metody dla obu klas.
Klasy muszą być generyczne czyli przechowywać dowolny typ danych zdefiniowany przy inicjalizacji obiektu. 
Metoda dodawania do poszczególnej struktury danych występuje w dwóch wersjach, dodawanie pojedynczego elementu lub kolejnej struktury danych tego samego typu.
 
Należy również zaimplementować Binary Search Tree, zgodnie ze specyfikacją dodać odpowiednie metody oraz zaimplementować przeszukiwanie wszerz i w głąb (BFS, DFS) przy wykorzystaniu kolejki oraz stosu. Przeszukiwanie w klasie BST powinno bazować na wzorcu strategii.
 
Do każdej z klas przygotować testy w JUnit (lub podobnym).
